# IO Poster

Промо-сайт автономной Digital Signage платформы IO Poster / LEDSouz.

## Product source of truth

- 640 × 640 × 1920 мм
- экран: 1520 мм
- робот: 360 мм
- верхняя полоса камер/датчиков: 40 мм
- 4 одинаковые LED-стороны
- экран и робот в одном внешнем контуре, заподлицо

Сайт статический и не требует сборки: откройте `index.html`.
