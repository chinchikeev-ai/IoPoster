# IOPOSTER.RU — Design System v1.0

**Статус:** утверждённый визуальный эталон для интерфейса IOPOSTER.RU (мобильный макет, 13.10.2026).

**Направление:** Premium Dark Minimalism / Subtle Glassmorphism / Cinematic Product Design.

> Это спецификация для дальнейшей реализации, а не утверждение, что существующий CSS уже ей соответствует. При разработке ориентироваться на последний утверждённый макет: тёмный минималистичный экран, крупное устройство в центре, тонкие надписи и полупрозрачные стеклянные кнопки. Не возвращаться к версии с яркими синими кнопками, неоновыми свечениями и перегруженными элементами.

## 1. Визуальная концепция

- Премиальный технологический продукт является главным визуальным акцентом.
- Глубокий тёмный графитовый фон, спокойное рассеянное студийное освещение.
- Много свободного пространства и простая иерархия.
- Тонкая геометрическая типографика, без тяжёлых заголовков.
- **Subtle Frosted Glass** для кнопок: сквозь поверхности слегка видно фон.
- Мягкие отражения от устройства допустимы; декоративный неон, свечение текста и яркие градиенты в UI — нет.
- В мобайл-версии всё важное находится в единой вертикальной композиции.

**Правило:** эффект создаёт сам продукт, а интерфейс не конкурирует с ним.

## 2. Шрифты

Точный шрифт на утверждённом изображении установить нельзя. Для реализации использовать ближайший по характеру:

- **Основной:** `Manrope Variable` (Google Fonts), с начертаниями 200–500.
- **Запасной:** `Inter Variable`, затем `-apple-system`, `BlinkMacSystemFont`, `sans-serif`.

| Элемент | Размер (mobile / desktop) | Weight | Letter spacing | Line height | Цвет |
|---|---|---|---|---|---|
| Логотип IOPOSTER.RU | 15–17 / 17–20px | 300 | 0.22–0.28em | 1.2 | #F5F6F8 |
| Hero — первая строка | 38–44 / 64–88px | 400 | -0.035em | 1.08–1.16 | #F5F5F7 |
| Hero — остальные строки | 38–44 / 64–88px | 200–300 | -0.035em | 1.08–1.16 | #B7B9C1 |
| Описание | 15–17 / 18–20px | 300–400 | normal | 1.5–1.65 | #A9ACB5 |
| Текст CTA | 16 / 16–18px | 400–500 | normal | 1.2 | #F5F5F7 |

Логотип — прописными буквами, с широким трекингом, без обводок и теней. Заголовок — по левому краю, без градиента и свечения. Не использовать начертания 600–900 для hero.

**Контент hero:**

> Реклама,  
> которая движется  
> к аудитории.

Подзаголовок:

> 360° Digital Signage, AI-консультант, навигация и автономная уборка — в одном мобильном устройстве.

## 4. Стеклянные кнопки — ключевой приём

Все основные CTA и управляющие элементы на тёмном фоне должны выглядеть как **полупрозрачное графитовое стекло**, а не как непрозрачная заливка.

### Основная кнопка «Смотреть продукт»

- Капсула: `border-radius: 999px`.
- Mobile: высота 52–58px, ширина 100% контейнера.
- Фон: `rgba(255,255,255,0.10–0.12)`.
- Размытие подложки: `backdrop-filter: blur(20px)`, с `-webkit-backdrop-filter` для Safari.
- Граница: `1px solid rgba(255,255,255,0.40)`.
- Белый текст 16px, вес 400–500, стрелка вправо на противоположном конце.
- Возможен почти незаметный внутренний блик и мягкий переход прозрачности.
- `hover` / `pressed`: небольшое увеличение непрозрачности, без яркого свечения; соблюдать `prefers-reduced-motion`.

Пример реализации (адаптировать под классы проекта):

```css
:root {
  --ui-bg: #0b0e13;
  --ui-text: #f5f5f7;
  --ui-muted: #a9acb5;
  --glass-bg: rgba(255, 255, 255, 0.11);
  --glass-border: rgba(255, 255, 255, 0.40);
}

.glass-button {
  display: inline-flex;
  align-items: center;
  justify-content: space-between;
  gap: 20px;
  width: 100%;
  min-height: 56px;
  padding: 14px 22px;
  color: var(--ui-text);
  background: var(--glass-bg);
  border: 1px solid var(--glass-border);
  border-radius: 999px;
  -webkit-backdrop-filter: blur(20px);
  backdrop-filter: blur(20px);
  font: 500 16px/1.2 "Manrope", "Inter", sans-serif;
  transition: background 200ms ease, border-color 200ms ease;
}

.glass-button:hover {
  background: rgba(255, 255, 255, 0.16);
}

.glass-button:focus-visible {
  outline: 2px solid rgba(255, 255, 255, 0.85);
  outline-offset: 3px;
}

@media (prefers-reduced-motion: reduce) {
  .glass-button { transition: none; }
}
```

**Важно:** `backdrop-filter` работает визуально только при полупрозрачном фоне и наличии деталей позади кнопки. Не делать стекло чрезмерно мутным или светлым. Сохранять читаемость текста и границ при отсутствии поддержки blur.

### Круглая кнопка меню

- 44–48px, круглые края (`50%`).
- Такой же приглушённый стеклянный материал, blur 12–20px.
- Тонкая светлая обводка.
- Три тонкие горизонтальные линии; без массивного квадрата или плотной тёмной заливки.

### Вторичные действия

- Визуально тише основного CTA: простые ссылки или очень лёгкие стеклянные поверхности.
- Не добавлять ряд одинаково заметных цветных кнопок под hero.

## 5. Композиция первого экрана (mobile-first)

1. **Header:** слева тонкий логотип IOPOSTER.RU, справа круглая стеклянная кнопка меню. Прозрачная панель без лишней подложки.
2. **Hero product:** большое реалистичное изображение устройства по центру, целиком, на тёмном студийном фоне, с мягким отражением на полу.
3. **Hero copy:** ниже устройства, слева, крупный светлый заголовок. Первая строка ярче, последующие тоньше и серее.
4. **Description:** компактный блок на 3–4 строки при доступной ширине, спокойный серый.
5. **CTA:** одна широкая полупрозрачная стеклянная капсула «Смотреть продукт» со стрелкой справа.

Не накладывать текст на экран устройства, не обрезать продукт и не увеличивать количество управляющих элементов ради заполнения пространства.

### Пространство и геометрия

- Боковые отступы mobile: 24–32px, с учётом очень узких экранов.
- Заголовок → описание: 20–28px.
- Описание → CTA: 28–36px.
- Радиус вторичных карточек: 20–28px.
- Safe Area на iOS учитывать; никаких перекрытий системными панелями.
- Ни горизонтального скролла, ни случайных пустых зон вверху/снизу.
- Desktop может использовать две колонки (текст слева, продукт справа) при сохранении того же характера.

## 6. Движение и взаимодействие

- Fade-in + смещение 8–16px при появлении: 500–800ms, `ease-out`.
- Лёгкое изменение фонового света; на desktop допустим едва заметный параллакс продукта.
- Hover и tap меняют материал кнопки очень умеренно.
- Не применять пульсацию, непрерывное вращение, сильный zoom, рывки и агрессивные анимации.
- Для `prefers-reduced-motion: reduce` убрать необязательную анимацию.

## 7. Продукт и достоверность рендера

Дизайн-система управляет **визуальной подачей сайта**, но не меняет утверждённые характеристики изделия. Сохранять геометрию и данные из корневого `README.md`: четыре одинаковые LED-стороны, единый внешний контур, размеры и конструкция.

Рендер должен передавать премиальную физическую фактуру устройства; не заменять его абстрактным цилиндром, смартфоном или произвольным экраном.

## 8. Запреты для ИИ-разработчика

- Никаких непрозрачных белых или ярко-синих CTA.
- Никаких сияющих синих бордюров, неоновых колец вокруг продукта и свечения букв.
- Никакой тяжёлой жирной типографики в первом экране.
- Никаких пёстрых карточек, массивных иконок и шумных паттернов.
- Никакой перегруженной или сжатой компоновки.
- Не изменять конструкцию и реальные характеристики оборудования.
- Не подменять утверждённый визуальный эталон собственными декоративными решениями.

## 9. Критерии приёмки

- [ ] Первый экран читается с мобильного и сохраняет главный акцент на продукте.
- [ ] Тонкий логотип и заголовок не выглядят тяжёлыми.
- [ ] Кнопка CTA заметно **полупрозрачна**; фон мягко просвечивает.
- [ ] Кнопка меню круглая и выполнена из того же стеклянного материала.
- [ ] Нет ярких светящихся UI-элементов, мешающих продукту.
- [ ] Нет пересечений с iPhone Safe Area и горизонтального скролла.
- [ ] Сохранены характеристики устройства из `README.md`.
- [ ] Анимации умеренные и отключаются для reduced motion.
